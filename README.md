এই repository তে Problem Solving with TypeScript & OOP অ্যাসাইনমেন্টের সমাধানগুলো সংরক্ষণ করা হয়েছে। এখানে TypeScript এর মৌলিক ধারণা, টাইপ সেফটি, জেনেরিকস, asynchronous programming এবং Object Oriented Programming (OOP) ব্যবহার করে মোট আটটি সমস্যা সমাধান করা হয়েছে।
solutions.ts ফাইল
সবগুলো কোডিং সমস্যার সমাধান একটি ফাইলেই রাখা হয়েছে: solutions.ts।

এই ফাইলে রয়েছে:

- Default parameter ব্যবহার করে multiplyValue ফাংশন
- Union type ও typeof type narrowing ব্যবহার করে processInput
- Readonly tuple ব্যবহার করে formatCoordinate
- Rest parameter ও generic ব্যবহার করে concatenateArrays
- Course interface এবং getPopularCourses ফাংশন
- keyof constraint-সহ generic pluckValues ফাংশন
- Employee ও Manager class-এর মাধ্যমে inheritance এবং access modifiers
- Promise<string> ও setTimeout ব্যবহার করে validateAgeAsync
  প্রতিটি function ও class method-এ প্রয়োজনীয় parameter এবং return type স্পষ্টভাবে উল্লেখ করা হয়েছে। কোডে any, sample test call এবং console.log রাখা হয়নি।

এই অ্যাসাইনমেন্টের মাধ্যমে TypeScript এর type system, generics, readonly tuple, Promise, interface এবং OOP এর গুরুত্বপূর্ণ বিষয়গুলো ব্যবহারিকভাবে অনুশীলন করা হয়েছে।
